# Authentication

- HTTP Authentication, scheme: bearer

- oAuth2 authentication. 

    - Flow: implicit
    - Authorization URL = [https://petstore.swagger.io/oauth/authorize](https://petstore.swagger.io/oauth/authorize)

|Scope|Scope Description|
|---|---|
|read:pets|read your pets|
|write:pets|modify pets in your account|

## DELETE 删除宠物

|名称|位置|类型|必选|说明|

> 返回示例

> 200 Response


## POST 上传宠物图片

POST /pets/{petId}/images

为指定的宠物上传图片。

> Body 请求参数

```yaml
additionalMetadata: ""
file: ""

```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |宠物的唯一标识。|
|petId|path|string| 是 |none|
|body|body|object| 否 |none|
|» additionalMetadata|body|string| 否 |Additional data to pass to server|
|» file|body|string(binary)| 否 |File to upload|

> 返回示例

> 200 Response

```json
{
    "code": 3,
    "type": "ex dolor",
    "message": "Pecus carcer cometes credo."
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|操作成功|[ApiResponse](#schemaapiresponse)|
